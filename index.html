About

I spent 17 years at NAVFAC as an Architectural Design Manager — delivering multi-million dollar infrastructure programs across complex federal environments. That work taught me how to manage ambiguity at scale, translate stakeholder needs into execution plans, and hold systems together under pressure.

Since 2025, I've applied that same discipline to data engineering and AI. I build medallion pipelines on Databricks, design dimensional models with dbt and Snowflake, and deploy LLM-powered applications that make data useful at the edge. I created Metric Muse as a personal brand to bring that capability to real-world data problems.

My current research initiative, ARC LAB, quantifies the carbon cost of AI workloads using public grid data — finding a 972 lbs CO₂/MWh savings opportunity by shifting AI compute to optimal hours.

ARC LAB — AI Carbon Intensity Research

Full Bronze→Silver→Gold medallion pipeline on Databricks using WattTime CAISO grid data to quantify the carbon cost of AI workloads by hour. Deployed a live Streamlit app with LLM-powered carbon forecasting, RAG assistant, token auto-refresh, and Parquet fallback. Key finding: scheduling AI workloads in hours 18–23 vs. 3–6 yields a 94% reduction in carbon intensity — 972 lbs CO₂/MWh.

Butterfly Effect — Film Hype Gap Analysis

Collaborative research pipeline analyzing how short-form media shifted film audience expectations across two eras (Pre Short-Form 2005–2014, Short-Form Era 2015–2025). Bronze/Silver/Gold pipeline on Databricks. Key findings: before 2015 zero over-hyped films; hype gap narrowed from −22.84 to −10.49; NLP analysis showed time-friction language +17.8%, craft critique +6.5%, and engagement language +29.4% in the Short-Form Era. Published as a GitHub Pages site with interactive visualizations.

Metrics Under Pressure — YouTube Analytics Pipeline

Production-style analytics engineering pipeline built on the YouTube Data API and Analytics API. Full dimensional model with SCD Type 2 on both channel and video dimensions — tracking historical metadata changes with effective_from/effective_to/is_current columns for point-in-time analysis. dbt transformations cover staging and mart layers with not_null, unique, referential integrity, and accepted_values tests. Airflow DAG orchestrates the full dbt lifecycle (deps → seed → run → test), containerized in Docker via Astronomer CLI.

Living 4 2Day — Nutrient Monitoring System

Multi-view Tableau analytics system for a hydroponics client tracking 7 nutrient parameters (TDS, pH, Ammonium, Nitrate, Carbonate Bicarbonate, Calcium, Potassium) across multiple reservoirs and seasons. Dashboard includes a KPI Trends view with current-vs-previous deltas, a Seasons view for cross-seasonal pattern analysis, and two Baseline views with hardcoded target thresholds (TDS 500ppm, pH 5.8, Nitrate 80ppm) enabling growers to identify drift before yield impact.
